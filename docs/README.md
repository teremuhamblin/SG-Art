# SG-Art — Documentation

Ce dossier `docs/` contient la documentation essentielle du projet **SG-Art**, un mini‑site artistique dédié au macramé.

## Contenu
- **overview.md** — Présentation rapide du projet  
- **structure.md** — Organisation des fichiers (HTML, CSS, JS)  
- **usage.md** — Comment utiliser, modifier ou étendre le site  
- **design.md** — Notes sur le style, couleurs et animations  

## Objectifs
- Fournir une base claire pour comprendre le fonctionnement du site  
- Documenter les choix techniques et artistiques  
- Faciliter l’évolution du projet SG-Art

## Fichiers principaux du site
- `index.html` — Structure du site  
- `style.css` — Style visuel et animations  
- `script.js` — Interactions et logique minimale

## Statut
Documentation légère, en cours d’expansion pour les futures versions SG-Art.
