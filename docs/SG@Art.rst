SG-Art — Documentation du dépôt
===============================

Ce dépôt contient un mini-site web optimisé composé de trois fichiers principaux.

Structure
---------

::

   index.html   → Page principale
   style.css    → Styles optimisés
   script.js    → Logique JavaScript légère

Objectif
--------

Fournir une base simple, propre et rapide pour un site artistique SG-Art.

Utilisation
-----------

- Modifier ``index.html`` pour le contenu
- Adapter ``style.css`` pour le design
- Ajouter des interactions dans ``script.js``

Fichiers ignorés
----------------

Le fichier ``.gitignore`` exclut :

- caches
- logs
- dossiers d’IDE
- fichiers temporaires
- environnements ``.env``

--------------

- [x] Structure minimale prête
- [x] Code optimisé
- [x] Dépôt propre
