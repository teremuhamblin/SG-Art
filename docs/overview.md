# Présentation — SG-Art

SG-Art est un mini‑site artistique dédié au macramé, combinant design manuel et esthétique numérique.

## Vision
Créer une plateforme simple, élégante et optimisée pour présenter des créations de macramé.

## Caractéristiques
- Interface minimaliste
- Identité visuelle macramé-tech
- Code léger et facilement extensible
