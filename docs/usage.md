# Utilisation du projet SG-Art

## Installation
1. Cloner le dépôt
2. Ouvrir `index.html` dans un navigateur
3. Modifier `style.css` ou `script.js` selon vos besoins

## Personnalisation
- Adapter les couleurs dans `style.css`
- Ajouter ou remplacer des images dans `images/`
- Modifier le contenu HTML pour vos créations
