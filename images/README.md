# SG-Art
- Dossier images/

Le dossier `images/` contient l’ensemble des visuels utilisés par le projet **SG-Art**.

## Contenu
- Photos pour le site  
- Illustrations et éléments graphiques  
- Images optimisées pour le web  

## Objectifs
- Centraliser toutes les ressources visuelles  
- Garantir une organisation claire pour le design du site  
- Faciliter la mise à jour ou l’ajout de nouvelles images

## Bonnes pratiques
- Utiliser des noms de fichiers courts et explicites  
- Optimiser les images avant ajout (poids, dimensions)  
- Conserver uniquement les visuels nécessaires au projet

## Statut
Dossier actif, mis à jour selon les besoins du site SG-Art.
